# SiteForge 安全与滥用测试

## 自定义模型 Base URL

自定义 OpenAI 兼容端点在任何额度预占或上游请求之前执行两层校验：

1. URL 与字面地址校验
   - 仅允许 HTTP / HTTPS
   - 禁止 URL 用户名、密码、查询参数和片段
   - 生产环境必须使用 HTTPS
   - 阻断 localhost、本地域名后缀、云元数据域名、IPv4/IPv6 私网、环回、链路本地、文档、基准测试与其他保留地址
   - 覆盖整数、十六进制、缩写 IPv4、IPv4-mapped IPv6 和 6to4 嵌入地址等 URL 解析绕过形式
2. DNS 解析结果校验
   - 请求前解析全部 A / AAAA 记录
   - 任一记录落入非公网地址即拒绝整个端点
   - DNS 失败和空记录返回脱敏错误，不暴露解析器内部信息

模型生成流和模型测连接口均禁止自动跟随 HTTP 重定向，避免公开端点跳转到内网或云元数据地址。

本地模型开发确有需要时可设置：

```bash
ALLOW_PRIVATE_PROVIDER_BASE_URLS=true
```

公共生产环境不得启用该开关。

## 品牌图片与资源上传

品牌资源库以及品牌套件内嵌的 Logo、深色 Logo、竖版 Logo、Logo Mark、Favicon 和 OG 图片，在写入或修改前执行内容级校验，而不是只信任浏览器提交的文件名和 MIME：

- Data URL 必须是标准 Base64，且解码后再次编码必须一致
- 以解码后字节数执行资源上限；品牌套件字段另保留更小的输入长度上限
- PNG、JPEG、WebP 和 PDF 必须匹配文件签名
- Logo、图片、图标和背景只能使用允许的图片类型
- 文档资源只能使用合法 UTF-8 纯文本或 PDF
- 修改品牌资源种类时，会使用存量内容与新种类的最终组合重新校验
- 校验失败发生在持久化之前，不会部分修改原资源或品牌套件

SVG 默认采用拒绝主动内容策略。以下内容不可进入资源库或品牌套件：

- `script`、`foreignObject`、`iframe`、`object`、`embed`
- `onload` 等事件属性
- 外部 `href` / `xlink:href`
- 外部 CSS、`@import` 和危险 `url()`
- `DOCTYPE`、`ENTITY`、`xml-stylesheet`
- `animate`、`set`、`discard` 等主动动画元素

该策略优先保证作为 Logo、图标和品牌图片使用时的静态安全性；需要复杂 SVG 动画的内容应在生成产物沙箱内单独处理，不能作为全局品牌资源上传。

## 跨账号资源隔离

所有需要登录的私有资源都同时使用资源 ID 和当前令牌中的用户 ID 查询。对其他账号的资源，接口统一返回 404，而不是返回 403 或不同错误，以减少资源枚举信号。

当前自动化矩阵覆盖：

- 项目读取、修改、删除和复制
- 项目版本读取、修改、新建和回滚
- 使用他人项目或版本创建发布
- 发布修改、重新发布和删除
- 品牌套件读取、修改、设为默认和删除
- 品牌资源修改和删除
- 项目、品牌资源与他人品牌套件的跨账号关联
- 列表隔离和所有者资源未被部分修改的事后验证

公开分享链接不属于账号私有资源；其删除权限由高熵删除令牌控制，需独立进行令牌与过期策略测试。

## 当前边界

本阶段显著收窄了 SSRF 攻击面，但 Node 全局 `fetch` 仍会独立执行实际连接时的 DNS 解析，因此“校验后到连接前瞬间切换 DNS”的 rebinding 竞态尚未通过 IP pinning 完全消除。后续完整防护应采用能够固定已验证地址的 HTTP dispatcher / lookup 回调，或将自定义厂商流量放入独立、无内网路由的出口代理。

品牌图片策略会拒绝主动 SVG，但它不是通用 SVG 清洗器。未来如需支持更复杂的 SVG 子集，应采用经过审计的白名单解析与重新序列化，而不是扩大正则放行范围。

## 回归测试

`apps/server/test/provider-url-policy.test.ts` 与 `provider-redirect-policy.test.ts` 覆盖：

- 私网、环回、链路本地、文档及保留地址
- IPv4-mapped IPv6 与 6to4 私网嵌入
- URL 整数、十六进制及缩写地址
- 混合公网/私网 DNS 结果
- DNS 失败、空记录与错误脱敏
- 生成和测连接口在网络访问前拒绝危险地址
- 模型请求不能自动跟随重定向

`apps/server/test/brand-asset-policy.test.ts` 与 `brand-kit-image-security.test.ts` 覆盖：

- 安全 PNG、SVG、文本和 PDF
- 伪造 MIME 与错误文件签名
- 畸形 Base64 和解码后超限
- 脚本、事件、外部引用、XML 实体和外部样式 SVG
- 品牌资源创建前拒绝和修改种类绕过
- 品牌套件内嵌图片创建与 PATCH 拒绝
- 校验失败后存量资源和品牌套件保持不变

`apps/server/test/resource-ownership-matrix.test.ts` 覆盖项目、版本、发布、品牌套件、品牌资源以及跨资源关联的账号隔离。
