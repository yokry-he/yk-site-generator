# 内置成品项目

SiteForge 内置项目用于让用户跳过模型配置和需求填写，直接从完整、可运行的网站开始。

## 用户路径

1. 打开 `/starters`。
2. 选择一个成品项目并点击“直接使用”。
3. 在本地工作台预览桌面或手机布局。
4. 使用可视化编辑器修改内容和样式。
5. 直接导出 HTML/ZIP 或创建临时分享。
6. 需要跨设备和版本管理时，再登录保存到云端项目。

## 当前目录

- AI 产品发布站
- 企业服务官网
- 个人作品集
- 餐厅预约主页
- 课程招生页
- 运营数据看板

每个项目都引用经过测试的官方模板，并使用完整的默认内容渲染，不依赖模型调用。

## 本地草稿

- 修改会在约 350ms 防抖后保存到浏览器本地。
- 最多保留最近 8 个内置项目草稿。
- 单个 HTML 草稿上限为 1.5MB。
- 用户可以随时恢复为内置初始版本。
- 本地草稿不包含模型 API Key，也不会自动上传到服务端。

## 产品原则

- 零配置路径必须始终可用，即使模型服务、模板 API 或登录服务暂时不可用。
- 内置项目必须是完整交付物，不得包含 lorem ipsum、未替换变量或空白占位按钮。
- AI 是可选的深度定制能力，而不是使用系统的前置条件。
- 登录是云端保存和版本管理的前置条件，而不是本地编辑、预览和导出的前置条件。
