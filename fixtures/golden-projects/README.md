# Golden Projects / 黄金样板工程

[中文](#中文) · [English](#english)

## 中文

本目录提交五套 Golden Project 的稳定描述，不提交生成后的大量源码。运行 `pnpm rc:golden` 会在 `artifacts/golden-projects` 物化完整工程、逐文件 SHA-256 清单和项目摘要。相同输入必须产生完全一致的文件摘要。

## English

This directory commits stable descriptors for five Golden Projects instead of checking in full generated trees. Run `pnpm rc:golden` to materialize complete projects, per-file SHA-256 locks, and the summary under `artifacts/golden-projects`. Identical input must produce identical complete-file fingerprints.
