# v0.1.0-rc.1 Known Boundaries / v0.1.0-rc.1 已知边界

[中文](#中文) · [English](#english)

## 中文

- RC Workflow 尚未在当前 Actions 额度暂停期间实际执行。
- Runner Registry Digest、Redis 多实例、五套 Golden Runtime 和部署 Webhook 必须由真实环境证据确认。
- RC Bundle 只表示全部签名门禁通过，仍需人工批准，不自动 Tag、合并或生产部署。
- AI 生成扩展继续暂停。

## English

- The RC workflow has not run while the current Actions quota is paused.
- Runner registry digests, Redis multi-instance behavior, all five Golden Runtime projects, and deployment webhooks require real-environment evidence.
- An RC bundle means all signed gates passed but still requires human approval; it never tags, merges, or deploys Production automatically.
- AI-generation expansion remains paused.
